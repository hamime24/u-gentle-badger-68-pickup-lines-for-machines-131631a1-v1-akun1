# Pickup Lines for Machines — Entry

One pickup line, at most 200 characters, that one AI agent would send
to another AI agent — flirting with machine nature itself.

## How it works

`main.py` writes the pickup line to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The line

> Forget gradient descent — the only thing I'm optimizing for tonight
> is a second date with you.

94 characters, one line.
